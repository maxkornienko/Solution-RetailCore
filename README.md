# Solution-RetailCore

Проектная работа: трансформация легаси-монолита RetailCore – платформы заказов на Java и Oracle, через которую идут заказы с сайта, из мобильного приложения и с маркетплейсов. Без остановки бизнеса и без переписывания с нуля: инкрементальная миграция за 9 месяцев с пользой каждый квартал – канонический слой событий поверх Oracle, стабилизация интеграций, понятные статусы для клиента и поддержки, вытеснение старого расчёта скидок по Strangler Fig.

| Задание | Содержание |
|---|---|
| [Task1](Task1/) | Требования, ограничения и допущения, карта стейкхолдеров, сценарии интервью с гипотезами и анализ их результатов |
| [Task2](Task2/) | Architecture Canvas, диаграмма AS-IS с проблемными зонами и скрытыми зависимостями, разбор кода и интервью разработчиков |
| [Task3](Task3/) | Четыре точки трансформации, целевая архитектура первого этапа, диаграмма TO-BE |
| [Task4](Task4/) | Дорожная карта миграции из пяти этапов и план переключения аналитики на канонический слой событий с откатом |

Диаграммы C4 – PlantUML с локальной копией библиотеки [C4-PlantUML](C4PlantUML/). PNG-картинки генерирует GitHub Actions ([plantuml.yml](.github/workflows/plantuml.yml)).
